<h1 style="text-align: left;"><strong>What is ModernTabs?</strong></h1>
<hr>
<p>It is a library mod that adds a <strong>cross-platform</strong>&nbsp;solution for <strong>customizing any creative tab</strong> even further than what is currently possible on both NeoForge and Fabric.<br>Currently implemented features:</p>
<ul>
<li>individual tab <strong>sections</strong> with a configurable banner &amp; overlay</li>
<li>The <strong>banner and overlay sprite animation</strong> can be <strong>configured</strong> to <strong>animate continuously</strong>, <strong>on hover</strong> or even <strong>not animate</strong> at all.</li>
<li>These <strong>sections can be configured</strong> to be <strong>collapsible</strong></li>
<li>customizable tab&nbsp;<strong>background</strong> sprite</li>
<li>customizable tab <strong>button</strong>&nbsp;sprite (the texture behind the icon)</li>
<li>Use <strong>any sprite</strong> as a <strong>tab icon </strong>without it having to be a registered item</li>
<li>customizable <strong>tab title</strong>&nbsp;that <strong>can</strong> also <strong>be replaced by a sprite</strong></li>
<li>customizable <strong>scroll bar</strong> sprite</li>
<li>a configurable <strong>search bar</strong></li>
<li>Any <strong>tab texture can be colored</strong> in a <strong>defined color</strong>.&nbsp;<br>&nbsp; &nbsp; &nbsp;If <strong>no texture</strong> is defined in most cases, the <strong>default texture will be used &amp; colored</strong>.</li>
<li>Support for custom <strong>element orientations</strong> (left, centered, right) for some tab elements</li>
<li><strong>KubeJs</strong> support since v1.5.0</li>
</ul>
<p>The creative tab banners are inspired by the&nbsp;<a href="https://www.curseforge.com/minecraft/mc-mods/create-aeronautics" target="_blank" rel="nofollow noopener">Create Aeronautics/Simulated</a> mod and ModernTabs therefore based on its original code.</p>

<h1><strong>FAQ</strong></h1>
<hr>
<p><span style="text-decoration: underline;">Why another such mod that adds creative tab banners?</span></p>
<p>➔ I created this library so I can use it for some upcoming mods by me and therefore, I need both a supported NeoForge and Fabric version. <br>Additionly, it already contains many other features with the goal of making the creative tab easier to configure.</p>
<p><span style="text-decoration: underline;">Will the Minecraft version x be supported?</span></p>
<p>➔ I will not backport it. If anyone plans on doing it, feel free to do it and if you want, you can create a pull request on GitHub. I might update it to newer versions in the future (but I will not guarantee it).</p>
